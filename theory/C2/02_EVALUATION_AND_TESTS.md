# C2：严格评估与压力测试

日期：2026-09-30。对象：`01_C2_THEORY.md` 中的限定命题和六个派生模块。

## 1. 评估结论

C2 已形成六个有明确输入、比较和边界的派生模块。核心进展是把若干简略概念变成可调用的数学接口，特别是双重统一化、两轴与分裂的分离、带见证的安全搜索压缩和有限模板下的问题选择。

本文完成的是：逐项数学审查、显式正反例、跨模块覆盖和小型精确回归。没有完成的是：证明助理形式化、独立同行认证、穷尽文献查重或同模型的 C1/C2 随机对照。因此不使用“C2 已提高 AI 创造力”的结论，也不把成功解释一个已知例子算作前瞻性预测。

## 3. 必须纠正的强读法

### 3.1 不能用非分裂群扩张代替两轴独立性

Frozen 派生层的两轴分别是：相对 profunctor 的可表示性、coend 复合比较是否为等价。它们不等于“每个点有 lift”和“存在同态截面”。

`RG2` 给出四种真假组合的总范畴模型。`RG3` 则证明：在 \(Q_8\to C_2^2\) 中，两轴都成立，仍无同态截面。故 twisting／分裂信息不是这两个布尔值的函数。代码对 16 个 coend 复合比较全部检出双射，对 8 个归一化截面全部检出不满足同态条件。

### 3.2 统一见证不等于乘积比较等价

`ES3` 把满射与单射分别变成“共同表示”和“共同等式”。对 \(\prod_i\mathbb Z/2^i\) 的局部化比较，右侧为零，但左侧有未被统一二幂杀掉的元素。因此共同存在的表述并未捕捉全部失败。

在空间值设置中，还需要全部同伦纤维信息；C2 未把集合级双射判据直接当作高阶版。

### 3.3 谱不是无条件的实际化判据

首次乘积失败基数只针对预先固定的函子和可用乘积。既要指定基数宇宙，也要处理“无失败见证”。没有左正合性、大小和表示性识别条件，保全部积仍不推出可表示。T11 给出实际反例。

### 3.4 静态充分与未来充分不能混用

`IC1` 的因子化只保留指定目标；`IC2` 和 `IC3` 另行要求未来动作稳定或逐状态反向提升。静态等价类里可以有一步到目标与永不到目标的两种状态。

### 3.5 不变分支不是相干规范选择

`DG2` 中不变 \(\pi_0\) 分支只是同伦不动点存在的必要条件；\(BQ_8\to B(C_2^2)\) 给出分支不变而截面不存在的情形。模板问题可枚举也不等于能够自动选择重要问题。

这些订正涉及派生解释，不修改 Frozen primitive core。

## 4.1 需要补充的短证明

**T05。** 取非零域 \(k\)，实际集合 \(A=k^{(\mathbb N)}\) 为有限支撑序列，形式集合 \(F=k^{\mathbb N}\)，比较为包含。有限阶段均为 \(k^n\)，比较为恒等。对 \(\xi=(1,1,\ldots)\)，所有有限实现纤维都是单点且相容；整体实现纤维为空。这精确隔离“塔有相干解”与“原实际世界可实现”。

**T10。** \(H(B)=\operatorname{Hom}(\{0,1\},B)\)。给 \(\{0,1\}\to\prod_iB_i\) 的映射等价于给每个 \(\{0,1\}\to B_i\)，故任意小积比较双射。ES2 中的 pro 对象就是常值二元素集合。

**T11。** 在有选择公理的集合论中，定义 \(H(\varnothing)=\varnothing\)，非空 \(B\) 则 \(H(B)=*\)。所有乘积比较都是双射，包括空积。但两不同映射 \(*\rightrightarrows\{0,1\}\) 的等化子为空，其 \(H\)-像的等化子为单点。所有余表示函子保等化子，故 \(H\) 不可余表示。此例击穿“只有乘积谱就能判定实际对象化”。

**T17。** 分裂扩张 \(\mathbb F_2^3\to\mathbb F_2^2\) 的同态截面为 \((x,y)\mapsto(x,y,ax+by)\)，\(a,b\in\mathbb F_2\)，恰有四个。

**T20/T21。** 输出为 \((0,0,0,1)\)，动作 advance 为 \((2,2,3,3)\)，stay 为恒等。当前输出合并0、1、2；一步观察把2与0、1分开。稳定商为 \(\{0,1\},\{2\},\{3\}\)。反例商合并0、1、2后，商上出现一步到目标的边，但这条边不能从原状态0提升。

**T22。** 群 \(C_2\) 与具有 \(e^2=e\) 的二元素幺半群，单对象、两箭头及恒等箭头数据相同，却有不同复合。它们的截断 nerve 在次数0、1相同，而次数2检测到差异。完整稠密性链的结论采用 Kerodon 8.4.1.14。

**T24。** 在 \(X=\{0,1,2,3,4\}\subset\mathbb R\) 上只保留中心探针 \(S=\{2\}\)，取 \(\delta=2\)。点0、4到2的距离相同，\(d_S(0,4)=0\)，实际距离4，正好损失 \(2\delta\)。

**T34。** 若含幺同态 \(f:\mathbb Q\to R\) 且 \(R\) 特征2，则
\(1_R=f(2)f(1/2)=0\)，所以 \(R\) 为零环。这不是缺一个巧妙构造，而是契约不相容。允许零环会改变原要求。

其余项目的证明在理论文件所列位置已经给出；不把执行有限近似当作无限证明。

# 6. 模块删除试验：究竟提供了什么信息？

这里删除的是某一项明确的数据或证明条件，而不是删除模块名称后禁止使用相同的经典数学。

| 删除内容 | 保留信息相同的情形 | 会错过的区别 | 结论 |
|---|---|---|---|
| EC 的定量值，仅保留可达／存在 | 两点底层集合相同、距离不同 | 数值误差与Lipschitz预算 | 定量信息必要；不证明统一Banach等理论已建成 |
| RG 的分裂／twisting，只保R/C真假 | 分裂 \(C_2^3\) 与非分裂 \(Q_8\) 扩张都R/C成立 | 有无同态截面 | twisting 必须独立保留 |
| ES 的共同等式，只检查共同表示 | 局部化比较右侧为零且满射 | 左侧的非零kernel | 仅见证存在不够 |
| IC 的反向提升，仅保静态目标 | 0和2当前输出相同 | 一步能否到目标 | 搜索压缩必须检查动作 |
| PR 的拓扑／完备性／预算 | 点态检测模式相同 | 一致或近一致提升能否成立 | 模式不能取代领域条件 |
| DG 的对称性与标记 | 同一底层向量空间 | 规范直线能否选择 | 问题选择依赖输入结构 |
| DG 的替代证明结构 | 最终命题同名 | 一条推导失效后有无另一证书 | 仅结论列表不够 |

这些是真实的信息损失证据。它们证明“使用时应保留这些结构”，不证明 C1 原理上无法表达这些结构。C2 的新增量是显式组织、定理与检查契约，而非扩大逻辑表达能力的形式定理。

# 8. 原创性、实际价值与成本

## 8.1 不应当算作新发明的部分

pro 表示、Yoneda、Reedy、中央扩张cocycle、紧致/Baire/Egorov、有限状态行为等价本身均为经典理论。特别是 IC2 与自动机／余代数分割细化直接相关；不能把有限状态最小化改名后宣称 C2 首创。外部研究已有通用余代数分割细化算法及复杂度分析（Wißmann 等，arXiv:1806.05654）。C2 没有证明优于这些算法。

## 8.2 本版有意义的构造性结果

ES5 从可数最终常值例子推广到任意无限极限序数，精确计算首次失效为共尾度。RG2/3 把两轴与分裂分离，使诊断不会把不同问题混同。IC1–IC3 把“可删信息”推进到带原状态提升见证的搜索商，IC4 给出近似多步压缩的误差传播。EC2 与 PR2 给出可量化的误差预算，而不只保留真假。

这些是本项目中可重用的数学结果与接口；其首次性未作穷尽检索。没有一项需要以“解决了某个大型未公开项目”来说明价值。

## 8.3 C2 的代价

C2 比 C1 多了表示、共尾度、coend、对称群、闭包和搜索商证书的准备成本。简单题强行调用全部模块会降低效率。求出最粗商、完整候选目录或全部等价类，本身也可能比直接解题贵。无限状态情形不能从 IC2 的有限终止推出可计算性。

所以“数学上避免漏解”不蕴含“总运行时间更短”；“结构更多”也不蕴含“创造结果更多”。最值得首先工程化的是 IC3 的可局部验证子类与 DG4 的证明依赖，以及IC4的近似误差证书；ES和RG按题目需要调用。

## 8.4 关于 AI 创造力的实际证据

本版没有运行相同模型、相同预算下的 A/B 对照。所有38个压力点都是已知或本稿构造、并与最终理论一起检查的例子；不属于隐藏答案的前瞻性测试。它们能说明逻辑接口是否工作，不能估计 C2 的净能力增益。

外部的 *Generative Modeling for Mathematical Discovery*（Ellenberg等，2025，arXiv:2503.11061）展示了 LLM生成＋问题特定评估的一种工作范式。它说明“生成后验证”已有成熟相关工作，但不验证 C2。C2 的目标必须与此类具体方法在相同预算下比较，而不是只与故意忽略相干性的错误基线比较。

# 9. 最终分项评估

| 项目 | 本版可支持的判断 |
|---|---|
| Frozen core 是否变化 | 没有；字节核对已执行 |
| 缺失功能是否被重新纳入 | 是；17项旧功能都有明确对应 |
| 是否比旧模块更精确 | 在类型、共同等式、两轴/分裂、动态压缩与模板选择上有具体改进 |
| 是否每个一般化版本都完成 | 否；明确限制普通／空间／有限／定量各适用域 |
| 是否出现新鲜的项目内数学推导 | 有；ES5、RG2/3及IC组合提供明确结果，但不主张文献首次性 |
| 是否实测提高 AI 创造力 | 尚未实测，不能给百分比或等级 |
| 当前最有实际作用的部分 | 保真搜索商、错误类型区分、有限状态持续观察、证明路径证书 |
| 最大剩余负担 | 自然问题建模、无限/高阶缩减、重要问题选择、验证器质量及实证对照 |

数学层未发现需要修改 Frozen core 的反例；这不是整个框架的一致性证明。可以把 C2 用作当前可选工具层，但不把它视为保证产生新数学的算法。
