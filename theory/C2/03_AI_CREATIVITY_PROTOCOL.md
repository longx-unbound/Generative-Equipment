# C2 的 AI 数学创造协议

这是一份可使用的工作协议与待执行的对照实验设计，不是实验结果。

## 1. 工作目标

从给定数学结构中提出精确且非平凡的问题、猜想、反例或构造，并产生可核验的证明。C2 提供可选模块，不要求每个问题都出现 Actual/Formal 缺口，也不要求每个任务都调用六个模块。

## 2. 输入契约

开始时固定：数学对象及假设；允许构造、等价与信息源；目标层次（存在性、分类、映射、算法或发现新问题）；验证办法；预算。新问题生成时，预先指定可用模板类型，但不预设答案。记录公开的候选、证明依赖和验证证书，而非要求不可获取的模型内部思维过程。

## 3. 最小操作循环

**提出候选。** 从DG模板、反例边界或给定结构提出一个明确候选。候选要能不用GE术语独立表述。

**选择必要模块。** 定量损失用EC；提升/复合/扭曲用RG；形式对象与共同阶段用ES；删信息或合并状态用IC；点态到统一用PR；对称选择与构造路径用DG。能直接解题时直接解题。

**寻找最小破坏例。** 针对具体推理删一个假设，检查是否仍成立。一次表示失败只排除该表示，不自动淘汰目标。一次成功构造也不保证所有选择相干。

**构造并验证。** 给出证明或反例；压缩附带提升证书；无限结论给一般证明，不只报有限程序输出。新对象还须验证保存契约。

**反馈。** 失败时区分命题为假、方法失败、缺少条件或尚未验证。成功时记录结论、条件、证明和可迁移部分。只保留对后续搜索有用的摘要。

## 4. 可直接使用的指令

> 使用 Generative Equipment C2 分析以下数学结构或问题。首先明确目标和允许的变化；从 EC、RG、ES、IC、PR、DG 中只选真正相关的模块。允许提出新的中间问题或构造，但须给出独立于 GE 术语的精确表述。对关键化简证明目标保持，对搜索商检查逐状态提升，对有限到无限步骤给出升级假设。优先产生一个可核验的非平凡结果，不以更多术语或更长报告代替进展。输出区分已证结论、反例、条件性结果和未验证候选。不要强行制造额外障碍；也不要把自然猜想或有限验算写成完整证明。

## 5. 对照组：区分C2贡献与一般提示作用

同一模型快照、任务、可用工具和总预算下，设四组：

| 组 | 条件 |
|---|---|
| A | 常规数学推理 |
| B | 同长度的普通证明检查表 |
| C | C1工作协议 |
| D | C2工作协议 |

必须同时做两种区分：

**整包效应。** 比较提供C1/C2完整材料后的总体表现，阅读与检索成本计入预算。

**组织效应。** 四组获得相同数学事实、定理与例子，只改变组织和调用协议。这样避免把“多给了正确数学知识”误判为新框架的独立优势。

必要时逐个删除C2模块，观察效果；删除名称而保留相同规则，不算有效消融。

## 6. 任务与污染控制

本版38个例子已经用于设计和检查，不能再作盲测。新的测试集至少覆盖：表示选择、提升/扭曲、无限统一化、动态压缩、定量分析、对称问题生成；同时含“无需额外结构”的控制题。

每个任务不仅要求解答，还可要求在一个定义清楚的新结构上提出一个可证明推广、反例或分类。题目生成规则、基线、预算、重复次数和停止规则在运行前固定。初次小样本只作试运行，不据此宣称统计优势。

在未知答案的公开问题上，由独立审查确认真值；不能用同一模型的自我评级作为唯一判定。训练污染只能降低，不能仅靠模型自称“不记得”排除。

## 7. 核心指标

主指标为固定总预算内，最终通过验证、相对预先固定知识库非重复且非平凡的产出数。同步记录：错误接受数、未验证数、拒绝／未完成率、验证成本和全部搜索成本。

创造性分开评估：**正确性**由证书决定；**新颖性**区分测试库新颖与文献首次性；**非平凡性**不能由定理长度决定；**用途**由外部任务、结构迁移或独立盲评决定。

拒绝一切候选可以降低错误率，所以必须同时报告有效产出和弃答率。产生大量未验证想法也不能提高主指标。

相同任务与重复种子作配对比较，报告原始数据、效果量与按任务聚类的不确定性。只有D相对C以及合理基线的净收益，才能支持“C2在该任务分布上有增益”；不直接推广到全部数学创造。

```json
{
  "task_id": "heldout-task-id",
  "arm": "C2",
  "model_snapshot": "record-actual-model",
  "budget": {"total_tokens": 0, "tool_calls": 0},
  "candidate": "precise mathematical statement",
  "assumptions": [],
  "modules_used": [],
  "proof_or_counterexample": "public certificate or artifact reference",
  "verification": "not_checked",
  "novelty_scope": "relative-to-fixed-corpus",
  "total_cost": {},
  "failure_type": null

```

此处数值是格式占位，不是运行数据。实际使用时替换为真实测量。

## 9. 当前可声明的能力

C2 已提供可推理的对象、比较、反例和有限可执行检查。它可以指导尝试数学创造；是否提高有效产出，需要上述实验。协议本身不能保证重要问题选择、通用完备搜索或新的数学突破。
